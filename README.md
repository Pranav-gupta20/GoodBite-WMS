🍽️ GoodBite – Food Wastage Management System

A Streamlit + MySQL based web app that helps reduce food wastage by connecting Providers (restaurants, mess, households) with Receivers (NGOs, shelters, food banks).

🚀 Features

👨‍🍳 Provider Dashboard – Add surplus food, track stock, manage claims.

🤝 Receiver Dashboard – Browse available food, place claims, track status.

🛠️ Admin Dashboard – Monitor stats, manage users, analyze food distribution.

📊 Analytics – Live statistics, claims analytics with charts.

🔒 Role-based Login System – Provider, Receiver, and Admin roles.

🗂️ Tech Stack

Frontend: Streamlit

Backend: Python (SQLAlchemy)

Database: MySQL

Visualization: Matplotlib, Streamlit Charts

📌 How It Works

Providers add surplus food listings.

Receivers view available food and place a claim.

Providers approve/reject claims → stock auto-updates.
